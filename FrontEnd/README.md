# Sabor e Clic — Protótipo Estático Completo

Abra `index.html`.

## Perfis incluídos

### Cliente
- Início
- Bancadas
- Minhas reservas
- Sessão atual
- Cardápio
- Carrinho
- Meus pedidos
- Meu perfil

### Cozinheiro
- Visão geral
- KDS
- Pedidos
- Disponibilidade do cardápio
- Histórico

### Administrador
- Dashboard
- Reservas
- Bancadas
- Produtos
- Ingredientes
- Substituições
- Usuários
- Relatórios

## Fluxos principais

### Cliente
Bancadas → Reserva → Sessão → Cardápio → Carrinho → Pedido → Acompanhamento

### Cozinha
Recebido → Em preparo → Pronto → Entregue

### Administração
Dashboard → Reservas/Bancadas → Produtos/Ingredientes → Substituições → Usuários → Relatórios

## Observação
Este é um protótipo estático: botões e trocas de tela simulam o comportamento da aplicação, sem backend ou banco.
